Conexão com Firebase Firestore

Posso usar o Firebase mesmo já tendo o projeto do app Pulso?
Sim! Você tem duas opções gratuitas na mesma conta Google:
  1. Recomendado: No Firebase Console, clique em "Adicionar projeto" e crie um projeto separado (ex: app-financeiro). O plano gratuito (Spark) permite vários projetos independentes na mesma conta!
  2. Alternativa: Usar o mesmo projeto do Pulso — este site grava tudo na coleção exclusiva app_financeiro_ciclo, sem misturar com as coleções do Pulso.
